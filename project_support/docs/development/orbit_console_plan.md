# 궤도 분석 화면 구현 계획

> 승인된 궤도 탭 설계를 구현한다. 계산과 화면은 독립적으로 시험하고 최종 통합 검토를 수행한다.

## 목표와 범위

현재 GP 데이터를 이해하고 원하는 위성을 찾아 관측 기하를 분석할 수 있는 공학용 화면으로 바꾼다. 시나리오와 임의 노드 정상률 및 전력/통신 합성 파형은 궤도 탭에서 제거한다. 다른 네 탭, 서버 API와 런타임은 유지한다. 새 장비 개념이나 미구현 계층을 만들지 않는다.

## 승인된 설계

왼쪽은 이름, NORAD, 궤도군, Epoch 경과를 표시하는 가상 스크롤 목록이다. 검색, 정렬, 궤도 필터와 관심 위성을 제공한다. 한 번 클릭하면 선택만, 두 번 클릭하거나 위치 보기 버튼을 누르면 카메라를 이동한다. 오른쪽은 선택 위성의 식별, 현재 전파값, 평균 궤도요소, 데이터 출처를 표시한다. 지구를 가리는 큰 모달과 가짜 상태 패널을 없앤다. 하단은 독립 UTC 분석 시계와 지상 관측 지점의 방위각, 고각, 거리 및 24시간 패스 표다. 간결한 구분선과 동일한 수치 단위, 밝은/어두운 테마를 사용한다.

## 데이터 계약

- GP는 CelesTrak 평균 궤도요소다. SGP4의 TEME 속력과 WGS84 지리 좌표를 표시하며 실측 텔레메트리로 부르지 않는다.
- 실 GP 전파 실패는 미제공으로 표시한다. 임의 궤도로 조용히 대체하지 않는다.
- demo=true 객체만 지구 자전 및 Kepler 운동에 따른 결정론적 모의를 허용한다. DEMO와 계산 모델을 명시한다.
- 지상 지점은 실제 안테나/장비가 아닌 좌표 기반 관측 기준점이다. 고도 미제공 시 0 km 가정을 명시한다. 패스는 고각 마스크를 기준으로 계산하며 기상, 지형, 굴절, 링크 가용성은 포함하지 않는다.
- 누락된 수치와 날짜는 0 또는 정상으로 치환하지 않는다. Epoch 경과와 계산 시각을 함께 제공한다.
- 분석 시계는 화면 상태다. 서버 SIM 시계나 다른 탭의 런타임을 변경하지 않는다.
